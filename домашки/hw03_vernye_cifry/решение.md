# Абсолютная и относительная погрешность — задачи 17, 18, 27

## Задача 17

Дано: a = 81,359, абсолютная погрешность Δ = 0,04. Определить количество верных цифр.

Цифра числа называется верной (в узком смысле), если абсолютная погрешность не превышает половины единицы того разряда, в котором стоит эта цифра: Δ ≤ 0,5·10^k.

Проверяем разряды:

```
десятки   (8): 0,5·10    = 5      ≥ 0,04 → верная
единицы   (1): 0,5·1     = 0,5    ≥ 0,04 → верная
десятые   (3): 0,5·0,1   = 0,05   ≥ 0,04 → верная
сотые     (5): 0,5·0,01  = 0,005  < 0,04 → сомнительная
тысячные  (9): 0,5·0,001 = 0,0005 < 0,04 → сомнительная
```

Ответ: верные цифры 8, 1, 3 — их три. Число корректно записывать как a ≈ 81,4 (± 0,04).

## Задача 18

Дано: x = 35,49 ± 0,002; y = 1,27 ± 0,003. Найти сумму и разность.

При сложении и вычитании абсолютные погрешности складываются: Δ(x ± y) = Δx + Δy.

```
x + y = 35,49 + 1,27 = 36,76
x − y = 35,49 − 1,27 = 34,22
Δ = 0,002 + 0,003 = 0,005
```

Относительные погрешности:

```
δ(x + y) = 0,005 / 36,76 ≈ 0,000136 ≈ 0,014 %
δ(x − y) = 0,005 / 34,22 ≈ 0,000146 ≈ 0,015 %
```

Ответ: x + y = 36,76 ± 0,005; x − y = 34,22 ± 0,005.

## Задача 27

Дано: a = ∫ от 1 до 2 √x dx ≈ 1,2188. Найти абсолютную и относительную погрешность приближения.

Точное значение:

```
∫₁² √x dx = (2/3)·x^(3/2) |₁² = (2/3)(2√2 − 1) = (4√2 − 2)/3 ≈ 1,218951
```

Погрешности:

```
Δ = |1,218951 − 1,2188| ≈ 0,000151 ≈ 1,5·10⁻⁴
δ = Δ / 1,218951 ≈ 0,000124 ≈ 0,0124 %
```

Ответ: Δ ≈ 0,00015; δ ≈ 0,012 %.
